# Fluxiq Labs

A lightweight, mobile-first editorial website for practical beginner guides.

## Structure
- `index.html`: homepage, styling and search/filter JavaScript in one file.
- `video-editing/index.html`: video-editing article and learning-resource CTA.
- `affiliate-marketing/index.html`: affiliate-marketing article and learning-resource CTA.
- `robots.txt`: crawler instructions and sitemap location.
- `sitemap.xml`: initial canonical URL list.
- `vercel.json`: Vercel clean URL settings.

## Deploy
The current canonical URLs are configured for GitHub Pages at `https://nouraofficial.github.io/Fluxiq-Labs/`. If you deploy to Vercel or connect a custom domain, update canonical URLs, Open Graph URLs, JSON-LD URLs, and `sitemap.xml` to the final production domain before submitting the sitemap to Google Search Console.

## Add an article
Create a new folder with an `index.html` file. Include a unique title and description, canonical URL, useful original content, relevant internal links, and an affiliate disclosure where needed. Add the page to the homepage and `sitemap.xml`.

The offer buttons currently point to the Fluxiq Labs Linktree as placeholders. Replace them with the correct tracked product links when available.
